## Regra de uso

Quando um novo chat precisar de conteúdo desses materiais:
1. consultar o repositório para descobrir qual fonte usar;
2. usar os arquivos do Projeto/ChatGPT quando estiverem disponíveis;
3. não substituir material-fonte por conhecimento geral sem sinalizar;
4. complementar com web apenas quando necessário e claramente identificado.
