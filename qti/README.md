# QTI — Motor de Quiz Interativo

Motor do projeto de Engenharia de Telecomunicações.

Fluxo: questão → resposta → correção → justificativa → próxima → resultado.

Arquivos:
- `index.html`: demonstração;
- `qti.css`: layout Dark;
- `qti-engine.js`: motor;
- `questions.example.js`: QTI-3 de exemplo.

O motor é genérico, mas a camada de conteúdo deste repositório deve conter somente matérias pertinentes à prova de Engenharia de Telecomunicações e Conhecimentos Básicos correspondentes.
