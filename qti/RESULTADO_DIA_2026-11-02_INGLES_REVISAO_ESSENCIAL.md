## Sessão de hoje — Modal Verbs

Treino dirigido com foco no valor semântico dos modais em contexto.

### Resumo obrigatório

| Ideia | Forma principal |
|---|---|
| possibilidade / probabilidade | **may / might** |
| possibilidade mais remota | **might** |
| obrigação | **must / have to** |
| obrigação no passado | **had to** |
| proibição | **must not / mustn't** |
| conselho / obrigação mais branda | **should / ought to** |
| capacidade / permissão | **can** |
| capacidade passada / possibilidade / pedido polido | **could** |
| futuro | **will** |
| hipótese / pedido / futuro do passado | **would** |

### Resultado do treino

- **14 questões** respondidas.
- **13 acertos / 14**.
- **Erro:** confusão entre **might** e **ought to**.
- Correção consolidada:
  - **might** → possibilidade/incerteza;
  - **ought to** → conselho/expectativa/obrigação mais branda.

## O que não pode faltar no dia da prova

### 1. Skimming e Scanning

- **Skimming** → ideia geral, tema, objetivo do texto.
- **Scanning** → localizar informação específica, palavra, referência, número ou detalhe.
- Não traduzir palavra por palavra; usar título, cognatos, contexto e palavras-chave.

### 2. Conectivos — função no contexto

| Relação | Palavras-chave |
|---|---|
| oposição / contraste | **however, nevertheless, but** |
| adição | **moreover, furthermore, in addition** |
| consequência / conclusão | **therefore, thus, consequently** |
| causa | **because, since** |
| condição | **if, provided that, unless** |
| concessão / contraste | **although, even though** |

### 3. Modal Verbs

Prioridade alta. A banca pode pedir o **sentido** do modal, não apenas sua tradução.

- **may** → possibilidade/probabilidade ou permissão;
- **might** → possibilidade mais remota;
- **must** → obrigação ou dedução;
- **must not** → proibição;
- **have to** → obrigação;
- **had to** → obrigação no passado;
- **should / ought to** → conselho ou obrigação menos intensa;
- **can** → capacidade ou permissão;
- **could** → capacidade passada, possibilidade ou pedido mais polido.

### 4. Referência pronominal

Ao encontrar **it, they, them, this, that, these, those, which, who, whose**, procurar o antecedente no texto.

Critérios:
- compatibilidade singular/plural;
- coerência semântica;
- normalmente o antecedente aparece pouco antes.

### 5. Tempos verbais pelo significado

- **Simple Present** → hábito, fato, verdade geral;
- **Simple Past** → ação concluída no passado;
- **Present Continuous** → ação ocorrendo agora;
- **Present Perfect** → passado conectado ao presente;
- **Present Perfect Continuous** → começou no passado e continua;
- **will** → futuro.

Ponto importante: **Simple Past e Present Perfect não são intercambiáveis**.

### 6. Countable × Uncountable / Quantifiers

- **many / few / a few** → contáveis;
- **much / little / a little** → incontáveis;
- **a lot of** → ambos;
- **enough** → suficiente.

Substantivos traiçoeiros: **information, advice, news, furniture** são normalmente incontáveis.

### 7. Conditionals

| Tipo | Estrutura | Ideia |
|---|---|---|
| Zero | if + present → present | fato, verdade, hábito |
| First | if + present → will/modal + verbo | situação possível/provável no futuro |
| Second | if + past → would/could/might + verbo | hipótese improvável/irreal |
| Third | if + past perfect → would have + particípio | passado que não ocorreu |

### 8. Passive Voice

Reconhecer imediatamente:

**BE + past participle**

Com modal:

**modal + be + past participle**

Na voz passiva, o foco está em quem/naquilo que sofre ou recebe a ação.

### 9. Reported Speech

Mudanças principais:

- present → past;
- past → past perfect;
- will → would;
- can → could;
- may → might;
- must → had to.

Mudanças de referência temporal/espacial importantes:

- today → that day;
- tomorrow → the next day;
- here → there.

### 10. Adjectives / Adverbs / Comparison

- adjective → modifica substantivo;
- adverb → modifica verbo, adjetivo ou outro advérbio;
- **-er than / more ... than** → comparative;
- **the -est / the most** → superlative;
- **good → better → best**;
- **bad → worse → worst**;
- **-ed** → como alguém se sente;
- **-ing** → característica que provoca o sentimento.

## Diretriz para a CESGRANRIO

Antes de escolher uma alternativa, perguntar:

> **Qual é a função dessa palavra ou estrutura neste contexto?**

Evitar escolher apenas porque a tradução parece adequada. Priorizar valor semântico, relação lógica, referência textual e coerência com o trecho.
