# Referência Metodológica

Este documento registra o que foi aproveitado do pacote metodológico analisado em 28/09/2026.

## Ideias mantidas
- recuperação ativa;
- prática espaçada;
- retestes;
- interleaving;
- correção imediata;
- análise de erros;
- confiança como sinal metacognitivo;
- transferência para questões diferentes;
- separação entre cobertura e domínio;
- acompanhamento por evidências;
- persistência de dados entre chats;
- QTI como instrumento curto de teste.

## Ideias adaptadas
- percentual de sessão não equivale automaticamente a domínio;
- domínio requer retenção e transferência;
- revisão D7/D21 é referência, não regra rígida;
- a agenda deve reagir a erro e confiança;
- as fontes de questões são específicas da CESGRANRIO e Telecom.

## Conteúdo explicitamente descartado
Qualquer disciplina, exemplo ou unidade de outro cargo, incluindo Banco de Dados, MER, Análise de Sistemas ou Infraestrutura que não esteja no edital de Engenharia de Telecomunicações.

O pacote original foi usado como inspiração arquitetural, não como matriz curricular.
