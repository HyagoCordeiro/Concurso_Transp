# Algoritmo de Agendamento — Versão Telecom

## Objetivo
Escolher o que estudar/revisar com base em evidência, sem abandonar a cobertura integral do edital.

## Prioridade de uma unidade

A prioridade deve aumentar quando houver:
- revisão vencida;
- erro recente;
- erro recorrente;
- baixa confiança;
- baixa retenção;
- alta recorrência histórica na CESGRANRIO;
- dependência conceitual para tópicos seguintes;
- proximidade da prova.

A prioridade deve diminuir quando houver:
- consolidação recente;
- bom desempenho em retestes espaçados;
- ausência de lacunas relevantes.

## Regras práticas

1. Reteste vencido vem antes de conteúdo novo.
2. Erro recorrente vem antes de uma nova questão equivalente.
3. Conteúdo nunca estudado permanece na fila de cobertura.
4. Não deixar uma matéria forte consumir todo o tempo apenas por conforto.
5. Não usar frequência histórica para excluir item do edital.
6. Quando houver erro localizado, aplicar micro-reparo em vez de reestudo completo.

## Intervalos

Padrão inicial:
- erro/baixa confiança: D1 ou D3;
- acerto com confiança média: D7;
- acerto sólido: D14/D21;
- consolidação: revisão mais espaçada.

Os intervalos devem ser ajustados por evidência posterior.

## Critério de consolidação

Uma unidade só pode ser candidata a CONSOLIDADO quando houver:
- mais de uma evidência;
- questão nova/transferida;
- reteste posterior;
- ausência de erro conceitual recorrente.
