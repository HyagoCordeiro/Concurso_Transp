# Decisões do Projeto

## 2026-09-28

1. O GitHub `HyagoCordeiro/Concurso_Transp` passa a ser o repositório central de continuidade.
2. A estratégia metodológica recebida será aproveitada **somente como ideia central**.
3. Nenhuma disciplina de Analista de Infraestrutura, Banco de Dados ou outro cargo será herdada.
4. Todo conteúdo deve ser adaptado ao edital de Engenharia de Telecomunicações.
5. O edital é a referência de cobertura.
6. CESGRANRIO/Transpetro/Petrobras Telecom calibram cobrança e profundidade.
7. QConcursos será usado como base complementar de questões.
8. O sistema deve registrar progresso, erros, retestes, confiança e revisões.
9. O QTI será o formato interativo padrão para blocos curtos de questões.
10. Materiais didáticos de terceiros não devem ser republicados integralmente em repositório público sem autorização; o repositório guardará referências, índices, notas e derivados próprios.
