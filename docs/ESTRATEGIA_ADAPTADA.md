# Estratégia Adaptada — Engenharia de Telecomunicações

## Escopo

Este projeto é exclusivo para a prova da **Transpetro / CESGRANRIO — Engenharia de Telecomunicações**.

A documentação metodológica original serve apenas como inspiração de estratégia. **Não herdar disciplinas, exemplos, unidades ou prioridades de outros cargos**, como Banco de Dados, Análise de Sistemas ou Infraestrutura.

## Princípios

O ciclo de aprendizagem adotado é:

```
EDITAL
  ↓
TEORIA NECESSÁRIA
  ↓
RECUPERAÇÃO ATIVA
  ↓
QUESTÕES CESGRANRIO
  ↓
CLASSIFICAÇÃO DO ERRO
  ↓
REPARO DIRECIONADO
  ↓
QUESTÃO ANÁLOGA / TRANSFERÊNCIA
  ↓
REVISÃO ESPAÇADA
  ↓
RETESTE
  ↓
CONSOLIDAÇÃO
```

## Hierarquia de fontes

1. Edital oficial da prova-alvo.
2. CESGRANRIO — Transpetro Engenharia de Telecomunicações.
3. CESGRANRIO — Petrobras Engenharia de Telecomunicações.
4. CESGRANRIO — Telecomunicações e áreas afins.
5. QConcursos como banco de consulta/classificação.
6. Questões autorais para reforço, variação de valores e transferência.

### Regra essencial

A frequência histórica das provas **não reduz o edital**. Ela serve para calibrar estilo, profundidade e prioridade.

## Estados de aprendizagem

- **NÃO INICIADO** — sem evidência de estudo.
- **ESTUDADO** — teoria vista e recuperação inicial realizada.
- **INSTÁVEL** — acertos existem, mas há oscilação, demora, baixa confiança ou erros recorrentes.
- **EM REVISÃO** — possui revisão/reteste pendente.
- **CONSOLIDADO** — desempenho consistente em questões novas e retestes posteriores.

Uma questão correta isolada nunca encerra um tópico.

## Como medir domínio

O domínio não é apenas percentual de acerto. Considerar:
- acerto;
- confiança;
- tempo;
- questão original vs. análoga;
- retenção após intervalo;
- tipo de erro;
- capacidade de explicar o conceito sem consulta.

## Duas filas simultâneas

### Fila de cobertura
Conteúdos ainda não vistos ou insuficientemente trabalhados.

### Fila de retenção
Revisões vencidas, erros recorrentes, tópicos instáveis e retestes.

A sessão diária deve combinar ambas.

## Ordem diária sugerida

```
1. Retestes vencidos
2. Erros recorrentes
3. Lacunas críticas
4. Conteúdo novo
5. Questões CESGRANRIO
6. Correção e reparo
7. Questão análoga
8. Registro
9. Novo agendamento
```

## Regra de reparo

Evitar reestudar capítulos inteiros por um erro localizado.

Exemplo:

```
erro em Nyquist
→ identificar se foi interpretação ou conceito
→ microexplicação
→ 2 questões de reforço
→ reteste posterior
```

## Probabilidade

Em Probabilidade, antes de qualquer fórmula:
1. traduzir o enunciado para eventos/símbolos;
2. destacar palavras como exatamente, pelo menos, no máximo, nenhum, ao menos um;
3. identificar união, interseção, complemento, condicional e independência;
4. só depois executar a conta.

## QTI

QTI significa bloco curto de teste interativo. Exemplos:
- QTI-3: diagnóstico/layout rápido;
- QTI-5: microteste;
- QTI-10: sessão curta de prática;
- QTI maior: simulado temático.

O QTI deve registrar resposta, gabarito, confiança, tempo, fonte, item do edital, unidade e tipo de erro.
